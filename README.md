# WorkItOutApp
An application for tracking your workouts in a simple way

10/03/2023
As of right now, the project still needs some of work to get to MVP
MVP In my mind means 
- Most importantly, you can create a custom workout
- second most, you can track at least the direct prior workout to compare against the current
-   Ideally, you can see all prior progress in a concise manner from somewhere on the workout screen, without losing current progress so you can easily see and then also record current, etc.
-     Info should include, date, workout length in time, the workouts and their results.
  
- You can set your basic information in your profile to get your BMI and track progress (not done)
-   ideally, there is a starting, a current, and a target weight or body option
-   as of right now, you can put in a current but it won't store the original or progress and image upload is purely cosmetic.
